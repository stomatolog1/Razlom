# Razlom

Музыкальное приложение для совместного прослушивания и создания общей волны.

## Веб-прототип

В папке `web` находится адаптивный интерфейс-прототип плейлистов и музыкальной коллекции. В нём можно переключать демо-плейлисты, искать и добавлять треки, создавать плейлисты и пользоваться демонстрационным плеером. Данные хранятся только в памяти браузера и сбрасываются при перезагрузке страницы; подключение к Go API пока не настроено.

Откройте `web/index.html` в браузере, чтобы посмотреть прототип.
