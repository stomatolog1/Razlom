# Razlom

Музыкальное приложение для совместного прослушивания и создания общей волны.

## Запуск приложения

Go-сервер раздаёт интерфейс из `web`, хранит данные в SQLite (`razlom.db`) и загруженные аудиофайлы в `uploads/`.
Для сессий задайте стабильный секрет не короче 32 символов.

```bash
export CGO_ENABLED=0
export RAZLOM_SESSION_SECRET="$(openssl rand -hex 32)"
go run ./cmd
```

Откройте [http://localhost:8080](http://localhost:8080). Зарегистрируйтесь или войдите: аккаунты и пароли (в виде bcrypt-хэшей) хранятся в базе. Добавление трека и социальных действий требует входа; каталог музыки и публичные профили доступны всем. Новые треки становятся общими и появляются у других слушателей автоматически при обновлении каталога (раз в 10 секунд).

В форме добавления трека можно загрузить MP3, M4A, AAC, OGG, WAV, FLAC или WebM размером до 25 МБ. Публичные плейлисты видны всем, приватные доступны только владельцу. На странице профиля отображаются публичные плейлисты и репосты пользователя.

Дополнительные переменные окружения: `RAZLOM_DB` (путь к SQLite), `RAZLOM_UPLOAD_DIR` (каталог аудио) и `RAZLOM_ADDR` (адрес сервера, по умолчанию `:8080`). Секрет сессии должен быть одинаковым у всех экземпляров сервера, которые используют одну базу.

## Администратор

Создайте обычный аккаунт и запустите приложение хотя бы один раз, чтобы база получила актуальную схему. Затем остановите сервер и назначьте администратором нужный аккаунт (подставьте его логин):

```bash
sqlite3 razlom.db "UPDATE users SET is_admin = 1 WHERE login = 'your_login';"
```

Перезапустите сервер и войдите в этот аккаунт — в навигации появится панель администратора. Обычные пользователи могут удалять только свои плейлисты, лайки и загруженные треки; администратор может управлять пользователями, треками и плейлистами. Удаление пользователя также удаляет его треки, плейлисты, лайки и репосты. Приложение не позволяет удалить текущий аккаунт администратора или последнего администратора.
